## Overview

Moonblade is a browser-based 2D action game developed from scratch on a raw HTML5 canvas without using an external game engine or third-party physics libraries. Built for the UTM Hackathon 2026, the game achieved a **Top 5 Finalist** ranking as a solo developer project.

## What I Built

As the solo developer, I built the entire game architecture and runtime systems from the ground up:

- **Gameplay Systems:** Custom game loop with fixed-timestep physics, velocity integration, frame-rate independent delta timing, and collision detection.
- **Combat Mechanics:** Hitbox and hurtbox calculations, attack timing windows, combo chains, parry mechanics, and distinct boss attack patterns.
- **UI & Presentation:** Health bars, status indicators, portrait-driven dialogue sequences, and scripted cutscenes rendered directly onto the canvas.
- **Progression Systems:** Multi-stage campaign progression moving through burning landscapes, frozen foothills, and dawn at Mount Fuji, featuring two distinct mini-bosses and a final boss duel.

## Decisions and trade-offs

**Zero external dependencies.** Building on bare canvas without heavy game engines meant zero load-time overhead, immediate start-up in any browser, and total control over loop scheduling and rendering layers.

**Modular architecture from day one.** Splitting the codebase into distinct modules—core loop, rendering, entities, bosses, campaign state, UI, and cutscenes—prevented spaghetti code and allowed fast iteration within hackathon deadlines.

**Data-driven scene configuration.** Backgrounds, parallax scroll rates, dialogue scripts, and enemy encounter timings were structured into configuration tables rather than hardcoded logic, making narrative pacing changes straightforward.

## What I learned

Writing an engine from scratch demystifies core game architecture: the fixed-timestep loop, velocity dampening, sprite layering, and state dispatching. Building it solo under hackathon time constraints highlighted the importance of clean component boundaries and prioritizing core gameplay feel over visual fluff.
