## Overview

Unsaid is an AI-powered cinematic conversation game where player dialogue choices directly shape character emotions, dialogue branches, and narrative progression. Built as a solo developer project for the Tencent Hackathon 2026, the game achieved a **Top 5 Finalist** ranking.

Rather than relying on static pre-scripted decision trees or unconstrained chatbot generation, Unsaid combines a deterministic narrative state machine with prompt-engineered LLM character personas, maintaining interpersonal tension and consistent dramatic pacing in real time.

## Problem

Traditional narrative-driven games rely on pre-written branching trees (like classic visual novels). While reliable, these trees scale poorly—exponential branching quickly forces writers to collapse storylines back into linear bottlenecks, making player choices feel superficial.

On the other hand, raw unconstrained conversational AI in games frequently breaks immersion: characters lose their emotional memory, hallucinate inconsistent backstories, drift out of tone, or produce rambling text that ruins cinematic dramatic timing.

The challenge was: how do you give players true conversational freedom without sacrificing story coherence, emotional continuity, and dramatic pacing?

## Approach

The core philosophy behind Unsaid is **guided emergence**:

1. **Dynamic Character Disposition State Machine:** Instead of branching the story on rigid binary flags, every interaction modifies an internal disposition vector (tracking trust, hesitation, defensiveness, and emotional volatility).
2. **Constrained Prompt Architecture:** Dialogue generation is bound to strict system prompts with explicit character behavioral boundaries and rigid JSON response schemas.
3. **Structured Response Contracts:** The AI does not output raw conversational text. It returns a structured JSON payload containing spoken dialogue, non-verbal emotional stage directions, disposition delta shifts, and narrative unlock flags.

## Technical Implementation

- **Frontend &amp; Cinematic UI:** Built with TypeScript and Next.js, featuring a distraction-free editorial interface with timed dialogue reveals, subtle typography transitions, character mood visualizers, and stateful sound cues.
- **Narrative Progression Engine:** A custom state machine that tracks conversation memory, emotional tipping points, and multi-turn dramatic beats. Story milestones only unlock when specific emotional thresholds are reached.
- **Backend API &amp; Context Management:** A lightweight API runtime that manages conversation session state, prunes token history to maintain tight context windows, and interfaces securely with AI endpoints.
- **Structured JSON Schema Enforcement:** Strict prompt contracts ensuring LLM responses parse deterministically into dialogue lines, stage directions, and numeric meter updates without runtime deserialization errors.

## Challenges

- **Sub-500ms Response Latency:** Cinematic games require tight conversational pacing. Waiting several seconds for an LLM response breaks dramatic tension. I optimized the prompt token footprint, pre-warmed connections, and implemented progressive text delivery to maintain conversational rhythm.
- **Hallucination &amp; Tone Drift:** LLMs often break character when challenged. I instituted strict persona boundaries within the prompt system and fallback disposition validation to prevent characters from agreeing too easily or losing their defined emotional traits.
- **Solo End-to-End Execution:** Developing the entire project solo—narrative writing, game logic, state machine architecture, UI design, and AI integration—demanded rigorous scoping to ensure a polished vertical slice before the hackathon submission deadline.

## Outcome

- **Top 5 Finalist at Tencent Hackathon 2026** among competitive submissions, developed end-to-end as a solo developer.
- Created a fully playable conversational vertical slice demonstrating responsive, emotionally grounded AI character interactions.
- Proved the viability of combining deterministic finite-state machines with generative AI in narrative game design.
